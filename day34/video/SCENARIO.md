# Day34 — сценарий видео

Сценарий исходной демонстрации. Live и локальные записи выполнены; итоги и
ограничения — в [RESULT.md](../RESULT.md). Медиа не включены в публикацию кода.
Плановая длительность: 2–3 минуты.
1. Показать чистую sandbox-копию: «Модель выбирает операции по цели и получает их результаты».
2. «Найди все использования API send_invite и объясни поток вызовов»: показать search/read нескольких файлов и ссылки в ответе.
3. Новый чистый запуск: «Обнови README по текущему поведению кода и покажи изменения».
4. Показать чтение кода, запись README, настоящий diff и сохранённый файл.
5. Показать команду воспроизведения и путь к трассе.

До записи: проверить обе цели на чистых fixtures и защиту sandbox.
Не подменять операции готовым отчётом; сохранённый запуск обозначать явно.
После: просмотреть инструменты/diff, проверить читаемость и отсутствие секретов; только затем отметить проверку.
