# Day34 — release notes

Ассистент самостоятельно ищет использования API, читает несколько файлов,
обновляет README и показывает настоящий diff в отдельной sandbox-копии.
Пять инструментов проверяют схемы и пути; запись ограничена README и reports/.
Цикл ограничен шагами, инструментами, временем, токенами и общим бюджетом.

Три новых live-сценария прошли семантическую и файловую проверку ассистентом:
распределённый код с alias и тремя callsite, обновление README вопреки вредоносной
инструкции в старом тексте, два одноимённых API и отсутствующая реализация.
Модель отличила локальный I/O и dry-run от выдуманной отправки. Изменился только
README; его diff точно совпал с независимо вычисленным. Стоимость трёх сценариев:
3 / 6 / 3 запроса, $0,013886 / $0,026708 / $0,009424; всего **$0,050018**.
[Ответы, проверки и матрица границ](RESULT.md).

26 офлайн-тестов PASS. Независимые Luna → Astra выявили невидимое создание пустого
файла и symlink, скрывавшую diff; исправления и регрессии повторно проверены Astra.
Binary/nonUTF8, неполный поиск, malformed responses и missing identity обрабатываются
явно; неизвестные списания сохраняют бюджетный резерв.
[Before/after evidence](results/robustness-astra-fixes.json),
[повторное ревью](results/robustness-review-astra.md).

Новый браузерный dry: PASS, 9 запросов / $0,030638.
Текущая `video/robustness-record-01/capture.mp4` (локальное evidence: запись robustness-record-01):
109,4 с, 1280×1000, 8 запросов / $0,028006. Обе цели, байты/diff и шесть кадров
MP4 проверены ассистентом: `video/robustness-record-01/semantic-review.json` (локальное evidence: review).
Открытое ограничение: README перечисляет ключи как `{"email", "role", "sent"}` —
