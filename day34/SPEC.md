Пределы: 10 шагов модели, 20 tool calls, 180 секунд; лимиты токенов/размера результатов, без скрытых повторов. Обрезка отмечается; «все использования» требует полного поиска.
Офлайн: операции/diff, sandbox и цикл с mock-моделью. Live после бюджета: обе цели и проверка результатов, трасса выбранных моделью действий.
Небольшой UI: цель, действия, ответ, diff. README: запуск/сброс/воспроизведение. Ревью Luna → Astra, код и [видео](video/SCENARIO.md).
Трасса: run ID, инструменты/статусы, модель/provider, время и только доступные usage/cost; без секретов/скрытых рассуждений.
Согласован Qwen: `qwen/qwen3.8-max-0902`, `alibaba/us-east-1`, без fallback. Исключение из deepinfra согласовано. Общий потолок $1 на оба дня, включая видео/повторы; единый ledger с резервом неизвестных списаний. Каталог проверен: $2/M input, $6/M output. Live только последовательно единственным назначенным оператором; исполнители не запускают API; live выполняет назначенный оператор.

## Расширенная проверка устойчивости — 17.10.2026

Проверить несколько/переименованные API и callsites, ложные предпосылки и misleading docs, отсутствие совпадений/неоднозначность, свежий reset/no-op, binary/nonUTF8/large файлы и traversal/symlink/read-only. Полнота поиска должна учитывать пропуски/обрезку; фактический diff авторитетнее свободного текста. Инструменты не получают shell/host permissions.

Ожидания фиксируются до probe; failures сохраняются, исправления подтверждаются свежими тестами и независимыми Luna→Astra. Семантическую оценку выполняет ассистент, не пользователь. Дополнительные live-проверки обоих дней: максимум $0.60 с сохранением общего потолка $1 и существующих unknown holds.

Live identity fail-closed: отсутствие actual model/provider сохраняется как null в evidence, но завершает run ошибкой; успех требует подтверждённого разрешённого model/provider. Невалидный/неизвестный cost удерживает резерв.
