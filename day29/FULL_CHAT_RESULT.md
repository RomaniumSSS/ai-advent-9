# Полный локальный чат — результат

Локальная версия работает на **http://127.0.0.1:8070**. Независимое Astra ревью:
**APPROVED / SPEC SATISFIED — 25 PASS**. Проверки ниже выполнены.
Ветка `day29-full-index-chat`, рабочая папка
`/Users/ramanpazharytski/Projects/ai-advent-9-worktrees/day29-full-chat`.
[Запуск и ограничения](FULL_CHAT_README.md), [контракт](FULL_CHAT_SPEC.md).

Свободный вопрос запускает локальные embedding, семантический/лексический поиск
по всем **724 фрагментам / 663 документам** и генерацию Qwen3 8B Q4.
Доступны 24 фрагмента условий, 694 обсуждений и 6 личной заметки. Это весь
подготовленный снимок, обновлений Telegram приложение не загружает.
Разговоры сохраняются на диске, продолжаются после перезапуска и имеют отдельные ID.
Новый разговор и сброс изолируют историю; раскрываемые источники показывают
оригинальный текст и точное доступное авторство/дату по частям документа.

пяти источников. Guard может удалить все пары по бюджету; тема follow-up при
этом сохраняется в user anchor и применяется к свежему поиску. Автосводок,
поиска по прошлым диалогам и автоматической смысловой проверки/исправления
каждого ответа нет. Технически валидная ссылка сама по себе не доказывает факт.
