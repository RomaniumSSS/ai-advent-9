# Локальный интерфейс Day24

Самостоятельный снимок рабочего прототипа от 04.10.2026. Код перенесён из личного `mentor/`; runtime-импортов из него или других дней нет. Вопросы самостоятельные: история сохраняет результаты, но не передаётся в контекст следующего вопроса.

## Обычный запуск

```sh
python3 -m pip install -r day24/app/requirements.txt
python3 day24/app/web.py --env-file /secure/path/.env
```

Открыть http://127.0.0.1:8050. Без `--env-file` ключ читается из `OPENROUTER_API_KEY`. Приложение слушает только `127.0.0.1`. Локальное хранилище по умолчанию `day24/app/private/`, можно задать `--data-dir /secure/path/to/state`.

### Необходимые данные и среда

Поиск в `search.py` использует SSH alias `crm-agent`, Python `/opt/day21/pipeline-venv/bin/python`, индекс `/opt/day21/private/index-release-v1` (Structure), локальный Ollama `127.0.0.1:11434` на VPS. В исходной среде это 724 чанка/663 документа, Qwen3-Embedding:0.6b, 1024 координаты. Индекс открывается только для чтения, эмбеддер проверяется по digest. Для своей среды нужно настроить эти пути и совместимый индекс; приватный индекс в репозиторий не включён.

Облачная генерация по умолчанию закрыта. Локальный `authorization.json` задаёт `approved`, `question_policy: arbitrary` (либо список `questions`), `identity_sha256`, разрешённые `document_ids` и `scopes`, модель `deepseek/deepseek-v4.1-flash`, провайдера `deepinfra/fp8`, общий `budget` и `retries: 0`. `identity_sha256` — SHA-256 канонического `common.packed(identity)`. Разрешение оформляется только после согласования данных и расходов. `search.manifest()` возвращает идентичность и список документов без текстов. Ключ в разрешении не хранится.

Общий `ledger.json` резервирует стоимость до вызова; неизвестный исход блокирует дальнейшие вызовы. Не копируйте состояние в новый каталог ради обхода бюджета. История и ключи не публикуются.

## Публичный режим для записи

```sh
python3 day24/app/web.py --port 8052 --public-only \
  --data-dir /secure/path/to/the-same-state \
  --env-file /secure/path/.env
```

Это тот же интерфейс и тот же путь обработки. Сервер разрешает только `scope=public`, фильтрует историю/чтение результатов/обратную связь. Текущий явный публичный список `PUBLIC_DOCUMENTS` содержит только `assignment:18`; индекс фильтруется до отбора кандидатов. На странице видна область, кнопки-примеры только заполняют поле. Введённый вопрос и комментарий тоже могут содержать личный текст — публичный режим не обезличивает их автоматически.

Полный локальный режим использует весь разрешённый корпус. Публичная запись демонстрирует механизмы на узкой области и не доказывает качество поиска по всему архиву.

## Как читать результат

«Цитаты проверены; смысл не проверен» означает, что ссылки и точные цитаты действительно присутствуют в переданных фрагментах. Это не обещание правильности вывода. Невалидный/обрезанный ответ хранится в диагностике, не отображается как проверенный. При пустом контексте запрос к генератору не выполняется.

Откройте источник для текста/цитат/авторов и дат. В диагностике отдельно показаны кандидаты, cosine, mixed, исключение порогом или top-K; выбранные и переданные материалы различаются. Точное условие запрошенного дня обходится без семантического порога, но не без ограничений области и размера контекста. Даты применяются до отбора; «последние дни» относятся к доступному архиву, не текущим новостям.

## Проверки

```sh
python3 day24/app/test_mentor.py
python3 day24/app/test_failures.py
python3 day24/app/test_quality.py
python3 day24/app/test_public.py
node --check day24/app/app.js
```

Это синтетические проверки, без генерации и внешней сети. Отдельно `python3 day24/app/check_assignments.py` читает реальный индекс через SSH и проверяет все 24 условия, не вызывает платную модель. `preview_fixture.py` — явно синтетический UI для проверки вёрстки, не реальная демонстрация RAG.

Старую историю Day24 можно импортировать из локальных артефактов командой `python3 day24/app/import_history.py --source day24/private --destination day24/app/private`; она обозначается как историческая. Эти приватные артефакты не входят в Git. [Общий отчёт](../VERIFICATION.md).
