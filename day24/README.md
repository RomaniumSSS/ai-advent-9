# День 24 — работающий RAG с цитатами и источниками

Основная версия — [локальное веб-приложение](app/README.md), приглушённая тёмная тема, собственные вопросы и кнопки-примеры. [Видео работы приложения](video/Day24-practical.mp4) показывает реальные HTTP-запросы, поиск по сохранённому индексу, ответы DeepSeek, источники и отказ при слабом контексте. Без озвучки.

## Что реализовано

- Вопрос → локальный эмбеддинг Qwen на VPS → поиск в SQLite Structure → отбор → DeepSeek через OpenRouter/DeepInfra.
- Ответ, source + section/chunk_id, дословные цитаты. Приложение проверяет, что цитаты относятся именно к переданному тексту, до отображения проверенного ответа.
- Источники раскрываются до текста чанка и отдельных сообщений с авторами/датами. Таблица диагностики показывает cosine, mixed и решение отбора.
- Пустой контекст: локальное «не знаю» с просьбой уточнить, без платной генерации. Ошибка модели/цитаты — отдельное состояние, а не успех.
- История результатов, обратная связь, контроль общего бюджета и повторной отправки; память беседы пока отсутствует.
- Точные условия заданий выбираются по метаданным. Для тематического поиска используется смешанная оценка 0.8 cosine + 0.2 совпадение слов, порог 0.35, K20→5. Явные даты ограничивают область поиска, «последние дни» отсчитываются от конца архива.

**Подлинная цитата не гарантирует правильность вывода.** Ограничения и реальные неуспешные случаи сохранены в [результатах](RESULT.md), проверки — в [VERIFICATION.md](VERIFICATION.md).

## Запуск

```sh
python3 -m pip install -r day24/app/requirements.txt
python3 day24/app/web.py --env-file /secure/path/.env
```

Открыть http://127.0.0.1:8050. Нужны доступ к настроенному индексу через SSH `crm-agent` и локальный Ollama на VPS; параметры среды описаны в [app/README.md](app/README.md). Ключ `OPENROUTER_API_KEY` хранится только на сервере. Облачная генерация без локального явного разрешения и бюджета выключена.

Приватный корпус, индексы, журнал расходов, ключи и история в репозиторий не входят. Код приложения самостоятельный и не импортирует модули других дней или `mentor/`.
