# Day24 — источники, цитаты и «не знаю»

Самостоятельная реализация на основе Day23: прежний Structure-индекс,
20 кандидатов → mixed score → до 5 чанков → ответ с источниками и цитатами.
Порог 0.35 применяется также к кандидатам по метаданным. Пустой контекст
даёт локальный отказ с просьбой уточнить, без платного вызова.

## Запуск

Python 3.10+, `pip install -r day24/requirements.txt`.
Файл вопросов: `{"cases":[{"id":"Q1","question":"Что сдаётся в Day21?"}]}`.

```sh
# На Mac, SSH crm-agent; индекс на VPS только читается.
python3 day24/prepare_ssh.py --questions /private/questions.json --output-dir day24/private/preparation
# Облачный вызов: только после согласования выборки и бюджета.
python3 day24/evaluate.py --prepared day24/private/preparation/prepared.json --output-dir day24/private/run-v1 --env-file /secure/.env --budget 0.10 --max-retries 2
python3 day24/report.py --prepared day24/private/preparation/prepared.json --run-dir day24/private/run-v1 --output day24/private/report.json
```

При пустом контексте ответ уже сохранён в подготовке; можно сразу строить отчёт.
Одинаковый run-dir сохраняет общий бюджет, включая повторы и видео. Успешные
вызовы не повторяются, неизвестные исходы требуют разбора. Новая папка не даёт
нового разрешения на расходы. Цены сверяются перед вызовом, резерв сохраняется
до HTTP; исходные ответы остаются приватными. Ошибка HTTP/формата не подменяется
утверждением «не знаю».

## Что проверяем

`answers.py` проверяет поля, источник среди переданных чанков и дословность
цитаты. Он **не проверяет смысл**: настоящая цитата может сопровождать неверный
вывод. Это отдельно оценивается по источникам в 10 контрольных вопросах.
У отказов пустые источники/цитаты ожидаемы и явно отмечаются в отчёте.

```sh
python3 day24/test_day24.py
python3 day24/test_evaluate.py
```

Это офлайн-проверки, HTTP подставлен. Реальные результаты и ограничения — в
[RESULT.md](RESULT.md). В `private/` находятся выбранные вопросы, контексты,
ожидания, trace, расходы и полный HTML. Переписка и личные заметки не публикуются.

Новые файлы: `retrieval.py` — отбор; `answers.py` — доказательства и отказ;
`prepare_ssh.py` — локальные эмбеддинги VPS; `prepare_saved.py` — повтор поиска
по сохранённым векторам без сети; `evaluate.py` — оплачиваемые ответы;
`report.py` — приватный отчёт. Runtime-импортов из других дней нет.
