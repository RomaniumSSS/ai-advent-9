# Day24 — приложение и реальные проверки, 04.10.2026

Основной результат теперь — [обычный веб-интерфейс](app/README.md): можно ввести свой вопрос, получить ответ с источниками/цитатами, открыть исходный текст и просмотреть решения поиска. [Видео](video/Day24-practical.mp4) записано с этого приложения; область публичных данных обозначена явно.

## Исправления относительно первой сдаваемой версии

- Условия явно указанных дней выбираются по `source=assignment` и `day`, не удаляются общим семантическим порогом. Реальная проверка замороженного индекса: **24/24 дня**, 22 условия ранее получали балл ниже 0.35. Проверка без платной генерации; это не 24 проверенных ответа модели.
- Авторы, даты и ID связаны с конкретными частями сообщений, передаются генератору и раскрываются в интерфейсе. Календарные ограничения применяются до отбора кандидатов.
- Цитаты проверяются относительно фактически переданных частей, а не всего сохранённого чанка. Полный чанк остаётся доступен для просмотра.
- Единственная внешняя Markdown-обёртка JSON обрабатывается явно, raw сохраняется. Неполный ответ модели помечается непроверенным, известная стоимость не превращается в неизвестный платный исход.
- Публичный режим ограничивает область, историю и чтение результатов на сервере. Действует общий журнал расходов, без повторной оплаты при повторе ID.

## Пределы результата

Рабочий интерфейс, настоящие источники и валидация не устраняют все ошибки. Модель может упустить важное, поиск — не найти нужное; память беседы пока отсутствует. Статус «цитаты проверены» не равен «ответ верен». Публичное видео на одном разрешённом документе показывает путь работы и доступные функции, а не полноту всего корпуса.

Новые расходы видео и технические проверки: [video/README.md](video/README.md), [VERIFICATION.md](VERIFICATION.md). Приватные доказательства остаются локально в хранилище прототипа; в Git только код, агрегаты и разрешённая публичная запись.
