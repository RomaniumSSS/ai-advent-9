# Практическое видео Day24

[Day24-practical.mp4](Day24-practical.mp4): 26.04 с, 1440×1100, без звука.
Новый вызов DeepSeek на условии Day18 и локальный отказ при оценке 0.287 < 0.35.
Публичный пример использует только условие из найденных чанков; отличие от полной
выборки обозначено на экране. Переписки и личных заметок нет.

`record_live.py` требует Playwright, Chromium, requests и ffmpeg. Запуск с
`--operate --env-file /secure/.env` делает платный запрос в общем run-v1 и бюджете
$0.10, поэтому требует действующего разрешения. Повтор уже снятого VIDEO01
блокируется. Для просмотра достаточно открыть MP4, повторять вызов не нужно.

`test_view.py` проверяет кнопку и вывод в браузере с подставленным ответом.
