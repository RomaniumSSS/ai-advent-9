**2 мин 03 с (122.84 с), 1440×1000, H.264, без озвучки.** Это запись обычного `day24/app/web.py` в Playwright, без подставленных ответов, специальных промптов для видео, слайдов или ускорения ожиданий. Ввод и клики автоматизированы; вопросы выбраны для демонстрации, ответы получены в ходе записи.

## Что показано

- Пример с кнопки: требования дня 18; новый ответ и открытие источника с цитатой.
- Введённый в поле вопрос: что должна сохранять и возвращать напоминалка из задания 18.
- Вопрос **без номера дня**: какой инструмент выполняется по расписанию и возвращает агрегированный результат. Настоящий векторный поиск: cosine **0.629**, mixed **0.617**, источник выбран по баллу, не по правилу номера дня.
- Посторонний вопрос о температуре выпечки: mixed **0.143 < 0.35**, локальное «не знаю» и просьба уточнить, облачных вызовов 0.
- Таблица оценок/отбора, раскрытие цитат; обновление страницы и чтение первого сохранённого ответа без повторной генерации.

Ориентиры: начало 00:00; первый запрос около00:09; второй около00:39; поиск без номера около00:59; посторонний около01:34; история в конце. Начальная задержка видеокодера учитывается приблизительно.

## Публичная область и доказательства

Видимая плашка: **«Публичный корпус: условие дня 18»**. Сервер ограничивает поиск одним разрешённым документом до формирования кандидатов. Поэтому таблица содержит один кандидат; это не демонстрация конкуренции всех 724 чанков. Полный приватный корпус проверялся отдельно, результаты описаны в [RESULT.md](../RESULT.md). Переписки и личных заметок в видео нет.

Три настоящих ответа DeepSeek/OpenRouter/DeepInfra, все прошли проверку подлинности цитат. Четвёртый вопрос — локальный отказ. Расход записи **$0.0005702984**; общий журнал прототипа после записи **$0.011628988 из $0.10**, неизвестных расходов0. Ответы публичного сценария сверены составителем по смыслу с условием; это не гарантия правильности любого ответа.

[RESULTS.json](RESULTS.json) содержит публичные вопросы/ответы, оценки и хеши кода/MP4. Исходный WebM, последовательность событий и полные runtime-результаты сохранены локально в `day24/private/interface-video/`, не публикуются.

## Повторная запись

Нужны Playwright/Chromium и ffmpeg. Сначала запустить обычное приложение с `--public-only`, тем же `--data-dir` общего бюджета и действующим разрешением генерации; см. [инструкцию приложения](../app/README.md).

```sh
python3 day24/video/record_app.py --operate --url http://127.0.0.1:8052
ffmpeg -i day24/private/interface-video/raw.webm -c:v libx264 -crf 20 \
  -pix_fmt yuv420p -an -movflags +faststart day24/video/Day24-practical.mp4
```

Повтор требует расхода в действующем разрешении. Скрипт отказывается автоматически перезаписывать начатый прогон; сначала изучите сохранённый результат. Для просмотра достаточно MP4, генерацию повторять не нужно.

`record_live.py` и `test_view.py` сохранены как исторические скрипты первой демонстрации. Они не создавали текущую запись и не являются основным пользовательским интерфейсом.
