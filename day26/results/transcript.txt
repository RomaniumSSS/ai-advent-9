[Средний] Объясни разницу между списком и множеством в Python. Дай короткий пример, показывающий удаление дубликатов. Не более 120 слов.
Список (`list`) сохраняет порядок элементов и позволяет дубликаты, а множество (`set`) не сохраняет порядок и автоматически удаляет дубликаты.  

Пример удаления дубликатов:  
```python
spisok = [1, 2, 2, 3]
mnozhestvo = set(spisok)  # {1, 2, 3}
```  
Множество удобно для работы с уникальными элементами, а список — для сохранения порядка.

[Сложный] Напиши функцию Python merge_intervals(intervals), объединяющую пересекающиеся интервалы. Вход: [[1,3],[2,6],[8,10],[10,12]]. Укажи результат для этого входа, сложность алгоритма и поведение при пустом входе. Интервалы, касающиеся концами, объединяются. Ответ до 220 слов.
Функция `merge_intervals(intervals)` объединяет пересекающиеся или смежные интервалы. Алгоритм работает следующим образом:

1. Сортируем интервалы по начальному значению.
2. Инициализируем список `result` для хранения объединённых интервалов.
3. Для каждого интервала:
   - Если `result` пуст, добавляем первый интервал.
   - Иначе сравниваем текущий интервал с последним в `result`. Если текущий начинается раньше или равен концу последнего в `result`, объединяем их (новый интервал — от минимального начала до максимального конца).
   - Иначе добавляем текущий интервал в `result`.

**Пример:**
Вход: `[[1,3],[2,6],[8,10],[10,12]]`  
Результат: `[[1,6],[8,12]]`

**Сложность:**  
- Сортировка: $O(n \log n)$  
- Объединение: $O(n)$  
Итог: $O(n \log n)$

**Поведение при пустом входе:**  
Функция возвращает пустой список `[]`.
