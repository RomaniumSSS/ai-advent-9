# Развёртывание дня 5 на Hetzner

Машина вне контура РФ, зарубежные API достаёт напрямую. Партнёрский h3llo не годится:
он в контуре РФ и до роутера HuggingFace не достучится.

## Что где слушает

| адрес | назначение |
| --- | --- |
| `0.0.0.0:8035` | чтение: страница, состояние, история. Публично |
| `127.0.0.1:8036` | запуск сравнения. Снаружи недостижим |

Разделение сделано потому, что в процессе живёт ключ OpenRouter, а TLS на машине нет:
домена у неё не куплено. Общий секрет в заголовке поверх открытого канала — замок,
ключ от которого слышно по дороге. Разведение адресов не передаёт по открытому каналу
ничего секретного. Локальный endpoint дополнительно принимает только JSON с локальным
Host и того же Origin, чтобы открытая в браузере чужая страница или DNS rebinding не
могли незаметно потратить кредиты.

Публичная страница показывает форму, но кнопка на ней заблокирована с подписью
«запуск только с машины владельца» — чтобы зритель понимал, что панель не сломана.

## Установка

    ssh hetzner
    sudo useradd --system --home /opt/ai-advent-9 --shell /usr/sbin/nologin ai-advent
    sudo mkdir -p /opt/ai-advent-9 && sudo chown $USER /opt/ai-advent-9
    git clone https://github.com/RomaniumSSS/ai-advent-9 /opt/ai-advent-9
    cd /opt/ai-advent-9
    printf 'OPENROUTER_API_KEY=sk-or-v1-...\n' > .env && chmod 600 .env
    sudo chown -R ai-advent:ai-advent /opt/ai-advent-9
    sudo cp day05/deploy/day05.service /etc/systemd/system/
    sudo systemctl daemon-reload
    sudo systemctl enable --now day05

Ключ берётся на `openrouter.ai/keys`. Ему можно задать потолок расхода прямо при
создании — для ключа, который лежит на публично доступной машине, это стоит сделать:
скомпрометированный ключ с лимитом стоит ровно столько, сколько на нём лимит.

Проверить, что `uv` лежит там, где ждёт unit-файл:

    which uv     # если не /usr/local/bin/uv — поправить ExecStart

## Открыть порт чтения

    sudo ufw allow 8035/tcp

**Порт 8036 не открывать никогда** — это и есть весь замок.

## Задать вопрос с ноутбука

    ssh -L 8036:127.0.0.1:8036 hetzner

и открыть `http://127.0.0.1:8036` — форма будет активна. Либо прямо на сервере:

    cd /opt/ai-advent-9 && uv run day05/compare.py --question "..." --runs 3

Удобно прописать алиас в `~/.ssh/config`, чтобы туннель поднимался одной командой.

## Проверка после установки

    systemctl status day05
    curl -s localhost:8035/api/state | head -c 200
    curl -s -o /dev/null -w '%{http_code}\n' -X POST localhost:8035/api/compare -H 'Content-Type: application/json' -d '{}'   # ждём 403
    curl -s -o /dev/null -w '%{http_code}\n' -X POST localhost:8036/api/compare -H 'Content-Type: application/json' -d '{}'   # ждём 400

Разница между 403 и 400 здесь и есть проверка: публичный отказывает по праву доступа,
локальный принимает запрос и ругается на пустое тело.

Проверить защиту браузерного endpoint:

    curl -s -o /dev/null -w '%{http_code}\n' -X POST localhost:8036/api/compare -H 'Content-Type: text/plain' -d '{"question":"x","dry_run":true}'
    curl -s -o /dev/null -w '%{http_code}\n' -X POST localhost:8036/api/compare -H 'Content-Type: application/json' -H 'Origin: https://evil.example' -d '{"question":"x","dry_run":true}'

Оба запроса должны получить отказ: `415` и `403` соответственно.

Снаружи, с другой машины:

    curl -s -o /dev/null -w '%{http_code}\n' -X POST http://<ip>:8036/api/compare -d '{}'

Должно не соединиться вообще. Если ответило — порт открыт, и это надо чинить.

## Расход

OpenRouter не берёт наценку за токен: платится цена провайдера, а комиссия удерживается
при пополнении баланса. Основную часть счёта делает старшая модель: у GLM-5.3 выход
стоит $4.00 за миллион токенов против $0.17 у младшей. Одно сравнение на трёх прогонах
обходится примерно в $0.02, но на задаче, где старшая модель упирается в `MAX_TOKENS`,
доходило и до $0.05 — без единого пригодного ответа.

Фактически списанное приходит в ответе полем `usage.cost` и сохраняется в сессии рядом
с нашим расчётом по прайсу. Расхождение между ними — единственный способ заметить, что
прайс в каталоге устарел: тесты этого поймать не могут, они сверяют формулу с собой же.

Панель показывает верхнюю границу расхода до запуска — по `MAX_TOKENS`, а не по
среднему. Среднее ничего не гарантирует.
