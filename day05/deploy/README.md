# Развёртывание дня 5 на Hetzner

Машина вне контура РФ, зарубежные API достаёт напрямую. Партнёрский h3llo не годится:
он в контуре РФ и до роутера HuggingFace не достучится.

## Что где слушает

| адрес | назначение |
| --- | --- |
| `0.0.0.0:8035` | чтение: страница, состояние, история. Публично |
| `127.0.0.1:8036` | запуск сравнения. Снаружи недостижим |

Разделение сделано потому, что в процессе живёт токен HuggingFace, а TLS на машине нет:
домена у неё не куплено. Общий секрет в заголовке поверх открытого канала — замок,
ключ от которого слышно по дороге. Разведение адресов дыру не смягчает, а убирает:
**по открытому каналу не передаётся ничего секретного вообще.**

Публичная страница показывает форму, но кнопка на ней заблокирована с подписью
«запуск только с машины владельца» — чтобы зритель понимал, что панель не сломана.

## Установка

    ssh hetzner
    sudo mkdir -p /opt/ai-advent-9 && sudo chown $USER /opt/ai-advent-9
    git clone https://github.com/RomaniumSSS/ai-advent-9 /opt/ai-advent-9
    cd /opt/ai-advent-9
    printf 'HF_TOKEN=hf_...\n' > .env && chmod 600 .env
    sudo cp day05/deploy/day05.service /etc/systemd/system/
    sudo systemctl daemon-reload
    sudo systemctl enable --now day05

Токен нужен **fine-grained, с галочкой «Make calls to Inference Providers»**.
Без неё роутер отвечает `403 — This authentication method does not have sufficient
permissions`. Обычный read-токен не подходит: чтение репозиториев и вызовы моделей
у HuggingFace разведены на разные разрешения.

Проверить, что `uv` лежит там, где ждёт unit-файл:

    which uv     # если не /usr/local/bin/uv — поправить ExecStart

## Открыть порт чтения

    sudo ufw allow 8035/tcp

**Порт 8036 не открывать никогда** — это и есть весь замок.

## Задать вопрос с ноутбука

    ssh -L 8036:127.0.0.1:8036 hetzner

и открыть `http://127.0.0.1:8036` — форма будет активна. Либо прямо на сервере:

    cd /opt/ai-advent-9 && uv run day05/compare.py --question "..." --runs 3

Удобно прописать алиас в `~/.ssh/config`, чтобы туннель поднимался одной командой.

## Проверка после установки

    systemctl status day05
    curl -s localhost:8035/api/state | head -c 200
    curl -s -o /dev/null -w '%{http_code}\n' -X POST localhost:8035/api/compare -d '{}'   # ждём 403
    curl -s -o /dev/null -w '%{http_code}\n' -X POST localhost:8036/api/compare -d '{}'   # ждём 400

Разница между 403 и 400 здесь и есть проверка: публичный отказывает по праву доступа,
локальный принимает запрос и ругается на пустое тело.

Снаружи, с другой машины:

    curl -s -o /dev/null -w '%{http_code}\n' -X POST http://<ip>:8036/api/compare -d '{}'

Должно не соединиться вообще. Если ответило — порт открыт, и это надо чинить.

## Расход

Кредиты HuggingFace бесплатного аккаунта — $0.10 в месяц, наценки HF не берёт.
Основную часть счёта делает старшая модель: у GLM-5.3 выход стоит $4.00 за миллион
токенов против $0.17 у младшей. Одно сравнение на трёх прогонах обходится примерно
в $0.02.

Панель показывает верхнюю границу расхода до запуска — по `MAX_TOKENS`, а не по
среднему. Среднее ничего не гарантирует.
