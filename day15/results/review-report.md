# Ревью Дня 15

Результат: после диагностического живого прогона исправлен переход по
обрезанному ответу. Внешняя FSM переходит к `LIVE_VALIDATION`; `CI` потребует
опубликованного SHA и успешного GitHub Actions run после отдельного решения.

Проверено:

- Ручные `/api/task/action` и CLI `/act` вызывают `Agent.apply_task`;
  `/api/workflow/approve` применяет сохранённое предложение через `SqliteStore`.
  Утверждение плана/финала сверяет версию. Ручной `submit_result` отклоняется,
  а workflow повторно сверяет version/status перед записью результата.
- Отказ в API/чате не меняет этап и версию; отдельный audit scoped по
  `user_id + task_id`. Отказ в чате не вызывает модель.
- `pause` блокирует переход, proposal переживает pause/restart/resume. `done`
  блокирует модель, новые переходы и паузу.
- SQL использует параметры; UI вставляет причины через `textContent`.
  `day01/`–`day14/` не менялись (кроме ранее существовавшего untracked
  `day14/.DS_Store`). Секреты не добавлялись.
- CI workflow имеет права только `contents: read`, запускается на push/PR
  затронутых путей и не содержит провайдерских ключей.
- Первый GitHub Actions run упал до тестов из-за `pip install -e .` в плоском
  учебном репозитории. Workflow переведён на `uv.lock`; точная новая
  последовательность команд локально прошла. [Отказ CI](ci-failure-01.md).
- Диагностический OpenRouter-прогон обнаружил `finish_reason=length` у трёх
  ответов и оборванный посреди таблицы runbook. Теперь такой ответ останавливает
  loop без перехода этапа; добавлена прицельная регрессия. Исправлено ошибочное
  ожидание evaluator: замечание к validation возвращает в execution.
- Второй диагностический прогон подтвердил новый guard на настоящем DeepInfra:
  ответ до 3200 токенов оборвался, задача осталась в `execution`. Для полного
  сквозного прогона увеличен лимит и сокращена формулировка одного задания;
  оба диагностических отчёта сохранены отдельно.

Найдены и исправлены при проверке: дублирование графа переходов, разрешённая
команда сменить этап через чат, пауза у `done` и отображение `active` на
финальном кадре. После исправлений прошёл полный локальный офлайн-набор и
браузерный сценарий; [тесты](test-report.md), [видео](video-report.md).

Итоговая реальная проверка: 14/14 ответов DeepInfra завершены без обрезки,
23/23 условий пройдены, три задачи в `done`; фактическое списание $0.00615348.
Трасса и диагностические прогоны — в [отчёте](live-run-01/report.md).

Ограничения: настоящий GitHub Actions run появится только после пуша.
Текстовый результат не доказывает выполнения внешних действий.
