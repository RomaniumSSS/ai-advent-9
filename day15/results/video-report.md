# Видео Дня 15

[Немое офлайн-видео](../demo/day15-controlled-transitions.webm), 13,72 с,
записано с текущего локального кода на свежей SQLite DB.

Последовательность: создание задачи в `planning` → попытка `planning → done`
и видимый отказ в UI/журнале → предложение плана → утверждение → автоматическое
выполнение и проверка → пауза → новый экземпляр агента → продолжение →
утверждение проверки → `done`.

Браузерный [отчёт](browser-report.json): 1280/768/375 px без горизонтального
переполнения, ошибок страницы нет. Отдельные кадры: [отказ](rejected-skip.png),
[проверка](validation.png), [финал](done-after-resume.png). Использован
офлайн-клиент: ролик подтверждает приложение и переходы, не качество ответа
реального провайдера.
