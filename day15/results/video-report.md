# Видео Дня 15

[Немое офлайн-видео](../demo/day15-controlled-transitions.webm), 13,72 с,
записано с текущего локального кода на свежей SQLite DB.

Последовательность: создание задачи в `planning` → попытка `planning → done`
и видимый отказ в UI/журнале → предложение плана → утверждение → автоматическое
выполнение и проверка → пауза → новый экземпляр агента → продолжение →
утверждение проверки → `done`.

Браузерный [отчёт](browser-report.json): 1280/768/375 px без горизонтального
переполнения, ошибок страницы нет. Отдельные кадры: [отказ](rejected-skip.png),
[проверка](validation.png), [финал](done-after-resume.png). Использован
офлайн-клиент: ролик подтверждает приложение и переходы, не качество ответа
реального провайдера.

## Ролик для сдачи

[Смотреть MP4 в Google Drive](https://drive.google.com/file/d/1JKKzrdfJurLZjVuug73tgE3O6He8onrE/view?usp=sharing)
или [локальный файл](../demo/day15-submission.mp4): 51,08 с, 1440×900, H.264,
страница без JS-ошибок. Запись создаёт `day15/demo/record-submission.py` на
свежей локальной SQLite DB.

В ролике крупно показаны: отказ от перескока `planning → done`, принятие плана,
автоматическое `execution → validation`, возврат с замечанием в `execution`,
повторная проверка, пауза, новый экземпляр агента, продолжение и финальное
принятие. Интерфейс записан с офлайн-клиентом; финальная карточка отдельно
указывает результаты [реального OpenRouter-прогона](live-run-01/report.md) и
[успешного CI](https://github.com/RomaniumSSS/ai-advent-9/actions/runs/35450831208).
Публичная ссылка проверена без входа в Google: HTTP 200, имя файла есть,
запроса доступа нет.
