# ai-advent-9

Задания AI Advent Challenge, девятый поток. Один день — одна папка `dayNN/`, самостоятельная
и законченная. Дни между собой кодом не связаны: `day05` не импортирует из `day04`, и так
задумано — каждый день должен читаться отдельно, как сданная работа.

## Границы

- **Сданные дни не переписываем.** День считается сданным, когда он в `main` и запушен.
  Если нужна правка в сданном — отдельная ветка и явное согласие Романа, не правка на месте.
- **`day04` не трогать вообще.** Ни рефакторинг, ни «заодно поправил».
- **Порт 8036 никогда не открывать наружу.** Публично слушает только `0.0.0.0:8035` — чтение.
  На 8036 висит запуск сравнения, и он обязан оставаться на `127.0.0.1`. Это не настройка,
  а единственный замок: TLS на машине нет.
- **Ключи только в `.env`** (chmod 600, в `.gitignore`). Значения ключей не печатать в чат
  ни целиком, ни частями — только длину или факт наличия.

## Инференс

Идёт через **OpenRouter**, не через HuggingFace: бесплатные кредиты HF кончились на пятом
задании. Ключ — `OPENROUTER_API_KEY`.

Провайдер **прибит к deepinfra** и запасные варианты отключены:
`{"provider": {"only": ["deepinfra"], "allow_fallbacks": false}}`. Это не перестраховка —
на этом держится сопоставимость с уже снятыми замерами. Тихой подменой железа испортился бы
столбец времени, ничем себя не обозначив. Падение при недоступности deepinfra — желаемое
поведение, а не баг.

`max_retries=0` у клиента по той же причине: один логический прогон должен означать ровно
один сетевой вызов, иначе `elapsed` склеит несколько попыток.

Бюджет ограничен (порядок — единицы долларов). Весь счёт делает старшая модель: сравнение
тройки на трёх прогонах стоит ~$0.078, та же связка без Kimi — ~$0.0011. Перед крупным
прогоном оценивать по потолку `MAX_TOKENS`, а не по среднему.

Фактически списанное приходит в `usage.cost` и сохраняется рядом с расчётом по прайсу.
Расхождение между ними — единственный способ заметить, что прайс в каталоге устарел:
тесты этого не поймают, они сверяют формулу с собой же.

## Как запускать

    uv run day05/compare.py --question "..." --runs 3
    uv run day05/web.py                  # панель: 8035 чтение, 8036 запуск
    uv run day05/test_compare.py         # офлайн-проверки, сети не требуют
    uv run day05/test_models.py
    uv run day05/test_web.py

Тесты — обычные скрипты с `main()`, не pytest. Печатают `ok`-строки или `FAIL` со списком.
Сети не трогают, поэтому гоняются свободно.

Если панель отвечает старым кодом — почти наверняка на порту висит прежний процесс, а новый
`uv run` молча не смог занять порт. Проверять `lsof -i :8036`, а не искать баг в коде.

## Замеренное — не пересчитывать

Числа из дня 5 получены живыми прогонами и стоят денег. Брать из README, не переснимать:
самый долгий ответ 243.7 с (Kimi K3), её пропускная способность гуляет между прогонами
в 7 раз, Kimi даёт 98.6% общего счёта. `REQUEST_TIMEOUT_SECONDS = 600` выбран как двойной
запас к измеренному максимуму, и на это есть проверка в тестах.

## Стиль

- Комментарии в коде объясняют **почему**, а не что. «Что» видно и так.
- Не глотать ошибки: пустое значение и ноль — разные вещи. Отсутствие `usage` даёт `None`,
  а не `0`, потому что ноль соврал бы, что вызов был бесплатным.
- **Комментарии, докстринги, README и разговор — по-русски. По-английски только коммиты.**
  Это отступление от глобального правила `~/.claude/rules/code.md`, где комментарии всегда
  английские, и оно сознательное: код здесь — учебный материал, который Роман читает, а не
  правит. Комментарий на неродном языке тормозит ровно того читателя, ради которого написан.
  Раньше в этом файле стояло «комментарии по-английски», но весь код дней 1–5 был русским —
  правило описывало не проект, а привычку, и молча не работало. Исправлено 08.09.2026.
