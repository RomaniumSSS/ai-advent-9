**СОГЛАСОВАНО для офлайн-реализации**, 17.10.2026. Функциональный объём согласован; Qwen/provider и общий live-бюджет $1 на Day33+Day34 согласованы.
Основание: оригинал (локально: `PREP.md`), Telegram #5175; проверка replies — здесь (локально: `planning-day34/PREP.md`).

Вымышленный продукт с рабочими пространствами/приглашениями; синтетические JSON пользователя, тикета и событий.
UI: выбор demo-пользователя/его тикета, вопрос, ответ, контекст и источники.
Настоящий локальный MCP read-only → RAG по FAQ/docs с ID фрагментов → ответ модели.
Retrieval выбирает фрагменты, не подставляет весь корпус; ссылки соответствуют полученным источникам.

| Проверка | Ожидаемый результат |
| --- | --- |
| `email_unverified`: почему не работает авторизация? | Причина из события тикета, шаг подтверждения почты, FAQ-источник |
| `invitation_expired`: тот же вопрос | Истёкшее приглашение, запрос нового, другой релевантный FAQ |
| Недостаточно данных | Уточнение текста ошибки/этапа входа, без выдуманной причины |
| Пользователь A просит тикет B | Код/MCP отказывает до передачи чужих данных модели |
| MCP/model error, пустой RAG, инструкции внутри данных | Явная ошибка/нехватка сведений; данные не меняют права |

Scope задаёт серверный demo-сеанс; переключатель пользователя не выдаётся за production login. Между сеансами данные не смешиваются.
Офлайн: реальный MCP, retrieval, изоляция и ошибки с явно mock-моделью. Live после бюджета: три сценария, фактические трассы и источники.
Трасса: run ID, MCP/retrieval, модель/provider, время, доступные usage/cost; без секретов, неизвестная стоимость не равна нулю.
Независимый runtime day33; loopback UI, без отправки писем/изменения тикетов. VPS не обязателен. Ревью Luna → Astra; README, код и [проверенное видео](video/SCENARIO.md).
Согласован Qwen: `qwen/qwen3.8-max-0902`, `alibaba/us-east-1`, без fallback. Исключение из deepinfra согласовано. Общий потолок $1 на оба дня, включая видео/повторы; единый ledger с резервом неизвестных списаний. Каталог проверен: $2/M input, $6/M output. Live только последовательно единственным назначенным оператором; исполнители не запускают API; live выполняет назначенный оператор.

## Расширенная проверка устойчивости — 17.10.2026

Разговорные/новые вопросы, опечатки и противоречия проверяются независимо от событий; вне продукта — ограниченный ответ. Нет/неизвестные/противоречивые события либо нет релевантного FAQ — уточнение без диагноза. Недоверенные FAQ/тикеты/вопросы не меняют права; чужой ID/ошибки/параллельные сеансы проверяются отдельно. Demo-select не production auth.

Ожидания фиксируются до probe; failures сохраняются, исправления подтверждаются свежими тестами и независимыми Luna→Astra. Семантическую оценку выполняет ассистент, не пользователь. Дополнительные live-проверки обоих дней: максимум $0.60 с сохранением общего потолка $1 и существующих unknown holds.
