# Происхождение

Самостоятельный минимальный пример на основе идеи Git-инструмента Day17
(day17/git_mcp_server.py на базе 0883264). Код написан заново для Day32,
не копирует SDK/MCP и не импортирует старые дни. Контракт диапазона 1..10 —
зафиксированный учебный предмет Day32. Проверяемая регрессия — <= 10 → < 10.
