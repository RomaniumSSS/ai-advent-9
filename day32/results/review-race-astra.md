# Day32 — сильное независимое ревью exact-SHA fetch

Reviewer: gpt-6-astra. **APPROVED — готовность нового dry/record.**
Проверка ограничена cli.poll, retry-областью recorder watcher, учётом read_retries
и связанными тестами; неизменённый core не пересматривался целиком.

Самостоятельно прочитан diff и review-race-luna.md. Теперь base/head из actual
API валидируются как полные40hex SHA до fetch. Fetch получает фиксированный
GitHub URL и эти два SHA; mutable refs/pull/N/head больше не используется.
GitSnapshot читает те же SHA, поэтому несовпадение API-снимка с продвинутым
remote ref больше не подменяет анализируемую версию и не оставляет head
незагруженным по причине выбора другого ref.

Recorder сначала полностью материализует list(poll), затем запускает Runner.
Read-only retry охватывает только poll/fetch/snapshot, сохраняет отдельное
событие read_retry и паузу. Он не включает модельный запрос и не снимает
persistent dedupe/резерв. Бесконечного ожидания в полном recorder нет:
родительский750s deadline и cleanup завершают собственный watcher. Generic
watcher loop по-прежнему предназначен для длительного polling.

Новых существенных дефектов в просмотренном исправлении не обнаружено.
Фактическая работоспособность GitHub fetch по SHA дополнительно сообщена
родителем; reviewer GitHub самостоятельно не вызывал. Локальный bare-remote
тест проверяет именно механизм несовпадения API SHA и продвинутого remote HEAD,
а не доказывает поведение GitHub сервера.
