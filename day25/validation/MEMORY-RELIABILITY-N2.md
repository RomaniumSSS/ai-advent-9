# N2 — опора для пользовательских утверждений

M2–M4/B2. Новые результаты имеют контракт `day25-chat-v4`; v3/v2 архивы сохраняют прежнюю проверку и raw. `user_facts.py` строит ограниченный4000bytes каталог: буквальные поля действующего task state и явные декларативные пользовательские реплики текущей версии в разрешённом хвосте чата. Вопросы о выборе, гипотезы, assistant messages и документы не становятся пользовательским фактом. Каталог не записывает и не изменяет task state автоматически.

Generation envelope отдельно содержит `user_fact_contract` с разрешёнными записями и точной схемой optional `user_fact_refs:[{fact_id,version}]`. Ссылки имеют строгие типы/версию/whitelist, UI показывает их буквальные statements через textContent отдельно от corpus sources. Обычный ответ без пользовательского выбора не требует refs. Refs не заменяют sources/quotes; исходный corpus `check_response` не ослаблен.

Для новых ответов wrapper проверяет пользовательские ссылки и явные формы персонального приписывания выбора/цели/запрета в answer и comparison aspect/analysis/reason. Свободное персональное утверждение должно быть буквально подтверждённой записью со ссылкой; иначе `unverified`, скрытый answer. Можно условно предложить вариант либо запросить уточнение. Неизвестный факт не подставляется из ассистентской истории или документа. Terminal и GET повторяют проверку по request snapshot; renderer заново получает проверенные записи, не доверяет сохранённым rendered metadata.

## Граница

Guard подтверждает типизированные буквальные записи и распознаваемые явные формы атрибуции. Он **не доказывает семантику любой свободной прозы**: парафразы, сложные отрицания/условия/конфликты решений требуют независимой смысловой проверки. Prompt рекомендует clarification при конфликте записей; он не гарантирует поведение модели. Невалидная запись даёт неуспешный исход, не переписывается в «правильную» автоматически. Saved all14 negative — офлайн регрессия, не новое live доказательство; public15 содержательная проблема остаётся отдельной. Provider/SSH0, старые live matrix/raw неизменны, A1FAIL сохраняется.

Gate контрпримеры исправлены: UI принимает v4 и отдельно маркирует исторический v3; executable JS regression проверяет вывод userfacts/литеральный HTML и скрытие unverified. Guard сопоставляет целую атрибутивную сентенцию с whole literal fact, не удаляет substring. Условность разрешена только для единственного приписывания с непосредственно относящимся к нему prefix; «вы выбрали X, поэтому может…», дополнительный выбор после поддержанного prefix и второе безусловное приписывание после conditional не проходят. Full Service negatives и whole matching positive проверены. Консервативные непонятные конструкции не получают success.
