## Изменения

- `app/task_contract.py`: извлекает явный лимит «Не более N предложений» из действующего task state; считает предложения только в answer, исключая JSON sources/quotes. Нумерация списка и десятичные точки не считаются концом предложения. Превышение даёт task_sentence_limit_exceeded.
- Service проверяет формат после неизменённого citation validator и повторно при terminal verified переходе. Ответ с хорошими цитатами, но плохим форматом становится unverified без answer; нет автоматического сокращения, retry или подмены источников. Отказ модели тоже не обходит превышенный формат.
- Реальный generation envelope получил answer_requirements: max_sentences, selected_user_choices (исходные уточнения с явным выбранным решением, включая SQLite), requested_tool_return для текущего вопроса, адресное guidance. Итог должен использовать выбранный вариант, а не список альтернатив; возвращаемый результат инструмента отделён от готового агента и формата сдачи. Это инструкции, не добавленные корпусные факты.

## Точная оставшаяся граница

Форматная проверка использует явный распознаваемый лимит и пунктуацию, не полный лингвистический разбор: необычная пунктуация/аббревиатуры могут требовать ручной проверки. Она запрещает лишние предложения, но не гарантирует достаточную полноту ответа.

Selected-choice/target guidance проверено в фактическом prompt, однако без новой генерации НЕ ДОКАЗАНО, что модель перестанет предлагать JSON вместо выбранного SQLite или назовёт верный возвращаемый результат. Произвольный смысл уточнений не превращён в хрупкий детерминированный запрет слов; цитата условия вправе упоминать JSON как допустимый вариант, хотя выбранный пример SQLite. Public9/all4 остаются NOT PROVEN по независимой смысловой оценке. Ни один прежний FAIL не закрыт этим ремонтом.
