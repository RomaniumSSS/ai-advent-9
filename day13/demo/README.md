# Видео дня 13

Цель ролика — за минуту показать наблюдаемый переход состояния и короткий
запрос к настоящей модели через онлайн-панель.

## Сценарий

1. На чистой SQLite-базе создать задачу с коротким чек-листом canary-релиза.
2. Нажать «Запустить до границы»: настоящий DeepSeek через OpenRouter создаёт
   planning proposal, но FSM остаётся на `planning` и ждёт человека.
3. Поставить задачу на паузу, создать новый экземпляр агента и продолжить:
   proposal и точка FSM сохраняются, повторного model call нет.
4. Пользователь вручную подтверждает план, результат и проверку. Код проводит
   `planning → execution → validation → done`, журнал показывает все версии.

Панель явно обозначает `ОНЛАЙН`. В ролике выполнен один настоящий provider call:
518 входных + 610 выходных токенов, reported cost `$0.0000852`. Полный
трёхходовый полуавтономный live-loop отдельно сохранён в
`../results/live-workflow/run-04/report.md`.

Итоговый файл: `day13-task-state.webm`. Это немой VP8-ролик 1280×800,
25 кадров/с, длительностью 49,68 с. Фактическая проверка кадров и контейнера
записана в `../results/video-report.md`.
