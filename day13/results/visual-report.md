# Визуальная проверка

Панель просмотрена после полного сценария в трёх viewport:

| Viewport | Артефакт | Результат |
| --- | --- | --- |
| 1280×800 | `viewport-1280.png` | четыре стадии в строку, карточка состояния и журнал видны одновременно |
| 768×1024 | `viewport-768.png` | стадии складываются 2×2, основные блоки идут одной колонкой |
| 375×812 | `viewport-375.png` | стадии, поля и кнопки складываются вертикально без горизонтального обрезания |

На всех размерах читаются objective, текущий шаг, ожидаемое действие, status,
version и журнал. Активная стадия `done` выделена одинаково; элементы управления
не перекрываются. Скриншоты получены локальным Chromium-сценарием, ошибок
JavaScript и `pageerror` не зафиксировано.
