# Day21: ограниченная проверка локального JSON Schema

Дата: 01.10.2026. Рабочий корень: `study`. Проверены только C01 и C02
разрешённого пилота v2: 2 кейса, 20 входных ID. Holdout и расширенная подборка
не читались и не запускались. Решения не применялись к корпусу.

## Изменения

- `run_local_sample.py`: в режиме `--schema` decisions задаются объектом с
  обязательным ключом каждого входного ID и затем нормализуются в прежний список.
  Смысловая рубрика сохранена; добавлена инструкция только о формате.
- Runner отвергает повторяющиеся ключи JSON и неверный формат schema-decisions.
  Malformed JSON и неверные типы фиксируются как ошибки отдельного кейса;
  пакет продолжает работу. `done_reason=length` не считается успехом, включая
  случай неразбираемого JSON. Измеренные usage и причина завершения сохраняются
  до разбора ответа. Ошибка выгрузки модели не перекрывает сохранённые результаты.
- Контрольная точка проверяет модель/digest, параметры, хеши входа и рубрики,
  системный промпт, режим схемы, выбранные case IDs и версию runner.
  Некорректные/повторные ID записи отвергаются. Совместимые завершённые записи
  сохраняются независимо от валидности ответа и не перезапускаются автоматически.
  Запись использует уникальный временный файл с правами 0600, flush/fsync и
  атомарную замену. Старые baseline-файлы не перезаписаны.
- `pilot_validation.py`: обязательные поля и типы проверяются явно; boolean
  не считается целочисленным ID. Проверяются причины, flags, полнота/дубли ID,
  состав include/review-групп, ссылки контекста и missing_context_ids.
  Неверные типы возвращают ошибки без исключения.
- `compare_pilot_v2.py`: неверный тип вывода/элементов decisions не прерывает
  сравнение. Смысловые регрессии остаются отдельными от структурных проверок.

## Проверки

В локальном Python 3.14/macOS выполнены:

```text
python3 day21/review/test_local_sample.py
python3 -m py_compile day21/review/run_local_sample.py day21/review/pilot_validation.py day21/review/compare_pilot_v2.py
```

Синтетические проверки без сети: пропущенные поля, неверные вложенные типы,
boolean ID, неизвестные flags, отсутствующие/повторные решения, неверное членство
групп, schema-normalization, malformed/duplicate-key JSON, несовместимые и
повторные checkpoint IDs, атомарный файл 0600. Интеграционный mock проверяет:
ошибка JSON первого кейса и length второго не мешают третьему; usage сохраняется;
повторный запуск не повторяет даже невалидные завершённые записи. Все прошли.
Это проверки runner, не измерения качества реальной модели.

Независимая повторная валидация прежних baseline сохраняет прежний итог:
cloud 10/10, local 7/10 структурно валидных кейсов. Новый stricter validator
не добавил ошибок к этим результатам. Скрипт сравнения не запускался с записью
существующего analysis-файла; проверка проводилась напрямую через validate.

## Реальный локальный эксперимент

Перед запуском проверено отсутствие другого runner. Существующий Ollama
слушает loopback `127.0.0.1:11435`; использована установленная `qwen3:8b`.
Параметры: `think=false`, temperature 0, num_ctx 8192, num_predict 2048,
`stream=false`, JSON Schema через format. Установок и скачиваний не было.

```text
python3 day21/review/run_local_sample.py --input semantic-pilot-v2-input.json --output semantic-pilot-v2-schema-local.json --cases C01 C02 --schema
```

Процесс завершился с кодом 0. Приватная контрольная точка:
`day21/private/semantic-pilot-v2-schema-local.json`, файл 0600, каталог 0700.
Она содержит исходный ответ модели, нормализованный вывод, ошибки, usage и
параметры. Публичный отчёт не содержит цитат сообщений или персональных данных.

| Кейс | Покрытие | Ошибки структуры | done_reason | Время, с | prompt_eval_count | eval_count |

не контролируемый benchmark производительности.

## Смысловой результат и ограничения

- C01: пропущенный прежним local ID4088 теперь присутствует, но получил include.
  Это оценочная реакция без технического вклада; рубрика требует exclude,
  и cloud исключил её. Все 10 include-ID разбиты на 10 одиночных групп,
  context_ids пусты. Полнота восстановлена, связность вопросов/ответов ухудшена.
- C02: все шесть заранее заданных регрессий проходят. Организационная ветка
  исключена, два технических вопроса сохранены вместе с короткими ответами.
  Все 10 статусов и состав пяти групп совпадают с cloud. Однако привязки групп
  к условию через context_ids отсутствуют; у cloud они сохранены.
- Проверка schema обеспечила полноту этих двух ответов и не выявила обрезания.
  Она не доказывает правильность смыслового отбора или связность документов.
  Нельзя переносить результат 2 кейсов на весь корпус либо на holdout.
- Автоматическая структурная проверка не устанавливает истинность утверждений,
  достаточность контекста или качество группировки. Формальная валидность C01
  совместима с показанными смысловыми дефектами.

Остановка: ограниченный эксперимент завершён. Следующий шаг определяет
родительский агент; новых прогонов, chunking, эмбеддингов и изменений корпуса нет.
