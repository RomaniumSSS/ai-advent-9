# Видео Day21

[Day21-demo.mp4](Day21-demo.mp4) — 90 секунд, 1280×720, H.264, без звука.

Это видеопрезентация с фрагментом схемы SQLite и агрегатами реального запуска, а не запись интерактивного терминала или повторной сборки. Приватные сообщения и авторы в кадры не включены. Перед созданием повторно запущен readonly inspector на VPS: ready, Fixed 685, Structure 724.

Источники чисел: ../review/DAY21-RESULT.md и ../private/index-final-evidence/inspection.json. Локальный render_demo.py создаёт кадры через Pillow и MP4 через ffmpeg; необходимы локальные evidence и системный шрифт Arial. Аудиодорожки нет. Проверены кадры, структура контейнера через ffprobe и полное декодирование через ffmpeg. Видео не опубликовано и задание автоматически не сдано.
