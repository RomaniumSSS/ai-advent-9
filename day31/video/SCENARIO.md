# Day31 — живая демонстрация

Согласуется вместе со [SPEC](../SPEC.md). Новые данные прогона, localhost,
видимый model/provider; ключи и приватные сообщения не показываются.

1. Открыть DevHelper и отправить `/help За что отвечают git_mcp_server.py, mcp_client.py и tool_calling.py в примере Day17?`.
   Дождаться результата конкретного запроса; показать ответ, README/docs и раскрыть
   реально использованные фрагменты с путём/строками.
2. Спросить `/help Какая сейчас Git-ветка?`. Показать настоящий MCP call/result
   и worktree. Совпадение с независимым `git branch --show-current` проверить
   отдельно и сохранить в результатах прогона.
3. Задать вопрос вне документации. Показать честную границу знаний.

CLI `/help` использует тот же обработчик; его проверка выполняется отдельно
и сохраняется в результатах. Видеозапись показывает только браузерные шаги 1–3.

Скрипт сухого прогона повторяет браузерные действия. Для записи запросы выполняются заново
реальной моделью; фикстура/старый вывод их не заменяют. Оба прогона входят в бюджет.
Записывается только свой viewport, ожидание реально, длительность заранее не задаётся.
Проверить ffprobe и кадры начала/ответов/конца, читаемость и журнал этой записи.
Публикация и изменения Git ради видео не требуются.
