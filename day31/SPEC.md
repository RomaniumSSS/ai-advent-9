**Результат.** Браузерный помощник и CLI `/help <вопрос>` объясняют структуру,
запуск и устройство знакомого Git MCP из Day17. Пользователь видит ответ,
фрагменты README/docs, текущую ветку и фактические этапы запроса.

**Объём.** В новом дне — свой README и небольшой docs-корпус с документированным
снимком Git MCP Day17, происхождением и версией. Старый Day17 не меняется и не
импортируется при запуске; FSM/память/старый чат не переносятся.
RAG: SQLite FTS5, фрагменты по заголовкам с путём/строками/хешем и ограниченный top-k.
MCP: отдельный настоящий stdio-процесс, discovery и read-only `git_context` с
фиксированным при старте Git-root; branch, head, detached. Модель root не задаёт.
Код выполняет поиск и MCP до одного запроса модели; автономный выбор tools не заявляется.
Пользователь дополнительно попросил сравнить GLM, DeepSeek и флагманский Qwen.
Сравнение — отдельный eval-прогон на одинаковых входных данных; три модели
выполняются параллельно по просьбе пользователя. Рабочее приложение
использует один выбранный профиль, без автоматической маршрутизации между моделями.

**Приёмка.** Вопросы о структуре/запуске/ограничениях дают ответы с корректными
ссылками на реально найденные фрагменты. Ветка совпадает с Git выбранного worktree;
detached HEAD и ошибки обозначены явно. Неизвестный вопрос не порождает выдуманных
файлов/функций. Изменение docs инвалидирует индекс. UI/CLI используют один обработчик.
Ключ остаётся на сервере, модельный HTML не исполняется, произвольные файлы не читаются.

**Проверки.** Целевые stdlib-тесты поиска/контрактов/ошибок; настоящий MCP временного
Git-репозитория; браузерный прогон. Независимые Luna → исправления Sol → Astra.
Моки отдельно от реальной генерации. Код+новая живая запись по [сценарию](video/SCENARIO.md).

**Среда.** Python/существующий lock, локальный интерфейс127.0.0.1:8071,
отдельные данные и результаты. После запрошенного пользователем сравнения выбран
OpenRouter `deepseek/deepseek-v4.1-flash`, endpoint `deepinfra/fp8`, reasoning выключен.
Резервные тарифы без скидки $0.20/M input и $0.60/M output, максимум1600 output tokens;
без fallback и скрытых retry. Актуальный разрешённый лимит Day31 — $1.10,
включая предметные проверки, сравнение моделей, сухие прогоны и видео; Day32 в него не входит.

**Границы.** Только чтение проекта/Git; без карточки выезда, CRM, редактирования
