# Видео дня 9

Короткая версия: [day09-panel-fast.mp4](day09-panel-fast.mp4), около 62 секунд,
ускорение ×1,25, 1440×1100, без аудиодорожки. Включена в Git.
Исходник: `day09-panel-silent.mp4`, 77.16 секунды. Исходник и промежуточные кадры игнорируются Git.

Сначала показаны реальные фрагменты `agent.py`: настройки, сборка контекста,
условие сжатия. Затем — работающая панель, контрольный вопрос в оба режима,
новое summary, расход и обновление страницы с сохранённым состоянием.

Первые 8 ходов восстановлены из реального диагностического
`results/openinference/project-r2.json`. На видео оплачены **только новые**
девятые ответы двух сторон и создание summary справа — три вызова OpenInference.
Применён итоговый промпт с ориентиром 120 слов. База записи временная,
рабочая пользовательская база не изменялась. Время ожидания не вырезалось.

Оба ответа правильно назвали проект, бюджет, актуальный срок, языки и
исключённую онлайн-оплату. Сам пересказ при этом содержит дополнительное
неподтверждённое исключение личного кабинета — это реальный дефект модели,
не исправленный вручную для видео. Summary хранит срок 18 октября потому,
что изменение на 25 октября находится в свежем хвосте; итоговый ответ
правильно использует новое значение из этого хвоста.

Артефакты:

- `recording-source.json`, `recording-meta.json` — источник первых ходов и метаданные.
- `left-calls.json`, `right-calls.json` — запросы и ответы новых реальных вызовов.
- `panel-results.json` — итоговое состояние панели.
- `visual-check.json` — отдельная проверка интерфейса с подставной моделью,
  её нельзя выдавать за реальную проверку провайдера.

Для повторной записи (будут новые расходы из общего ledger):

```bash
uv run day09/demo/serve_recording.py --env-file /путь/к/.env \
  --report day09/results/openinference/project-r2.json
# В другом терминале, Python с установленным Playwright Chromium:
python day09/demo/record.py
```

Нужны Playwright Chromium и ffmpeg. В проверенной macOS Playwright доступен
через `/opt/anaconda3/bin/python`, зависимости агента — через `uv run`.
Перед повторной записью сохранить прежние demo-артефакты отдельно:
скрипт записывает видео и файлы с фиксированными именами.

Ускоренная версия получена из исходной записи фильтром ffmpeg
`setpts=PTS/1.25`; новые API-вызовы не выполнялись, сцены не вырезались.
