## Модель риска

Правки могут пройти тесты на знакомые фразы, но пропустить иные продолжения; новая тема может наследовать старую цель; «verified» может маскировать неверный смысл или придуманный выбор; попытка увеличить число ответов может ослабить источники; новый live-run может быть ошибочно засчитан без отдельного лимита.

N2 должен показать конкретный механизм и негативные примеры; если локальная проверка неуверенна, ответ должен быть условным или запрашивать уточнение. Это не повод объявлять M3 PASS по одному regex.
