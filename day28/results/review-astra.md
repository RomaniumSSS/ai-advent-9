### Корректность изменения

Модель теперь выдаёт `{answer,source_refs}`; приложение отображает указанные ею
источники и копирует их полный исходный текст во внешний `{answer,sources,quotes}`.
Это соответствует SPEC: каждый предъявленный источник из выбранного контекста,
его цитата дословна, ошибки проверяются кодом. SPEC не требует, чтобы модель сама
перепечатывала каждый символ quote. Правка не меняет модель, индекс, embedding,
разрешённые внешние действия или исторический replay.

- S1/S2 присваиваются одному и тому же выбранному списку при сборке messages,
  сохранении source_reference_map и materialization. После отбора текста нет
  нормализации/усечения; text в сообщениях и quotes равны. Используются только refs,
  указанные моделью; соседние selected автоматически не добавляются в sources.
- Неизвестные, повторные, нестроковые ссылки, неправильные поля и ответ без ссылок
  без маркера нехватки сведений отклоняются. Корректность самого unknown — смысловая оценка. При ошибке проекция не публикуется. Public/all
  guard остаётся прежним; map строится из selected, не из полного индекса.
- Сырой Ollama response и parsed raw_model_answer сохранены отдельно от внешнего
  ответа. `response_format`, `source_reference_map`, `citation_mode` позволяют
  воспроизвести происхождение каждой проекции. Исходный answer модели не исправляется.
- UI выводит: «Модель выбрала источники; приложение показывает их оригинальный текст»;
  смысловая обоснованность отдельно требует оценки. README/RESULT/RELEASE_NOTES
  явно объясняют происхождение quotes. Это не заявление, что модель побайтно

- Replay выбирает прежний SCHEMA и validator без materialization. Исторические
