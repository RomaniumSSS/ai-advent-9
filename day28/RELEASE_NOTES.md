# Day28 — локальная LLM + RAG

Прежний Structure-индекс подключён к самостоятельным локальным UI/CLI: query embedding,
поиск и генерация выполняются на Mac через Ollama. Public UI показывает ответ, выбранные
моделью источники, их неизменённые оригинальные фрагменты, run/request IDs и времена фаз.
Полный корпус доступен явно через приватный CLI; индекс не пересчитывается.

Проверены 31 офлайн тест, responsive fixtures, 3×2 новых E2E и отдельный dry run.
E2E: 6/6 валидных исходов, подтверждённые факты и честный unknown; составное сравнение
E02 частичное. Пары ответов совпали, но трёх сценариев недостаточно для общей гарантии
стабильности. Время E2E — 23.26–52.50 с. Семантику оценил агент, не пользователь.

Exact replay исторических messages сохранён отдельно: два из трёх локальных ответов
отклонены строгой проверкой источников/цитат, три cloud ответа имеют валидные цитаты.
Cloud данные от 03.10.2026; нового облачного speed benchmark и платных вызовов нет.
Новый E2E source_refs протокол показывает доказательства приложения, не копированные
моделью цитаты. Ошибки прежних серий и replay не скрыты.

[Живая запись 2:59](video/Day28-live.mp4) проверена: три новых запроса,
ffprobe/полное декодирование, кадры и соответствие API. [Evidence](results/video-verification.json).
Публикация и пользовательская сдача не заявляются. Корпус/private
receipts не входят в публичные материалы; соседние дни и общие зависимости не менялись.
Usage/cost разработки не предоставлены; экономия от распределения моделей не измерена.
