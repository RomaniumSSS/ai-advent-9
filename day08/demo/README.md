# Немая запись дня 8

Видео дня 8: [смотреть на Google Drive](https://drive.google.com/file/d/1pOyMp1717Ih83KvAF9KnrmES7CE0iBzH/view?usp=sharing).

[Ускоренная версия ×1,5](day08-panel-fast.mp4) — 1:01, без звука.

[day08-panel-silent.mp4](day08-panel-silent.mp4) — 1:31, 1440×1000,
H.264, около 3,4 МБ. Аудиодорожки нет. `day08-demo.mp4` содержит ту же новую версию.

В кадре только исходный код и настоящая браузерная панель. Четыре сообщения
отправлены в OpenRouter, gpt-oss-20b через CoreWeave. Видны токены запросов и
ответов, накопленная сумма, обновление страницы с сохранением расхода и
локальный отказ при демонстрационном лимите 6000. Реальное окно модели больше;
это показ работы локальной защиты, а не новый тест отказа провайдера.

Для записи использовалась временная база. Ответы сохранены в
`panel-recording-results.json`: сумма входов 1431, выходов 387,
фактическая стоимость показана в ответах API. На экране кода показаны настоящие
фрагменты `agent.py` и `store.py`, без подмены реализации.

Воспроизведение (macOS/Python, установленный Playwright Chromium, ffmpeg, uv):

```bash
uv run day08/demo/serve_recording.py --env-file /путь/к/.env
# В другом терминале, Python с установленным Playwright:
python day08/demo/record_panel.py
```

Сервер записи слушает только 127.0.0.1:8048; API-вызовы платные, клиент
ограничен бюджетом $0.03 на панель. Обычные пользовательские базы не открываются.
MP4 и промежуточные файлы исключены из Git.

Проверены кадры, декодирование файла и отсутствие аудиопотока. В браузере
проверены суммы после сообщений и перезагрузки, локальный отказ без API,
а также отсутствие горизонтального переполнения на ширинах 1280, 768 и 375.
Видео подготовлено для просмотра; публикации и сдачи не было.
