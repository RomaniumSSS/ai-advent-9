День 7 — контекст, переживающий перезапуск

Слева и справа — два объекта Agent внутри одного процесса, с раздельными конфигами и раздельной историей. Проверка дня 6: напишите слева «меня зовут Роман», затем «как меня зовут» — вспомнит. Тот же вопрос справа — не вспомнит. Проверка дня 7: остановите сервер (Ctrl+C), поднимите заново, обновите страницу — переписка на месте, всё до черты приехало с диска. Под каждым ответом строка дебага: модель, время, токены, цена.
