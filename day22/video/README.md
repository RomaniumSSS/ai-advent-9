# Практическая запись Day22

Основной файл: `Day22-practical.mp4`,61.24с,1440×1000,безозвучки.
Это запись работающего Chromium, а не набор слайдов.

1. Показ реальных функций rank/messages из rag.py.
2. Ввод Q01 и настоящий SSH-запуск prepare на VPS.
3. Показ top-5, времени7.33с и найденного условия Day7.
4. Переключение сохранённых ответов OpenRouter:plain/rag,модель,usage,cost.
5. Итоги20ответов/10пар и ограничения.

Новый поиск проверен на точное совпадение chunk_id/text с контекстом
первого прогона. Ответы взяты из реальных файлов run-v1; это явно подписано
в кадре. Новых платных вызовов нет. Чатовые тексты в видео скрыты.
Сервер съёмки остановлен после записи; порт8052 слушал только loopback.

serve_live.py — ограниченная панель съёмки для Q01; общий интерфейс агента
остаётся CLI rag.py. record_live.py записывает браузер через Playwright,
ffmpeg конвертирует запись в MP4. Для записи нужны Playwright и Chromium;
они не являются зависимостями самого RAG.

Day22-demo.mp4 — прежняя презентация, оставлена как дополнительный обзор.
