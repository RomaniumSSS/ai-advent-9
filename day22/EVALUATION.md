# Как сравниваем ответы Day22

Набор из questions.json фиксируется до первого запуска. Это 10 учебных
вопросов по условиям и заметке; не репрезентативный тест всего архива.
Индекс поиска содержит весь замороженный корпус, без фильтра по эталону.

## Поиск — отдельно от ответа

Для каждого вопроса сохраняем ранжированный список выбранных chunk_id,
document_id и cosine. Проверяем присутствие каждого ожидаемого document_id
в переданном контексте (доля найденных ожидаемых документов и число вопросов,
где найдены все). Для заметки наличие документа не гарантирует нужный абзац:
смотрим, содержит ли фактический текст необходимые сведения.
Эталонные ID и ожидаемые факты в промпт генератора не передаются.

## Ответ — разбор по фиксированным ожиданиям

Родительский агент проверяет каждый ожидаемый факт по тексту ответа:
присутствует / частично / отсутствует. Отдельно отмечает фактические ошибки,
выдуманные требования и корректный отказ при недостатке данных.
Это разбор агентом, не независимая человеческая приёмка и не автоматическая
оценка простым совпадением ключевых слов. Положительные и отрицательные
результаты сохраняются; эталон под ответы не подстраивается.

Для RAG дополнительно проверяем поддержку утверждений переданными чанками.
Ссылка с верным ID сама по себе не доказывает подтверждение утверждения.
Без RAG отсутствие источников не штрафуется: сравниваем правильность фактов,
а не наличие недоступного контекста. Отказ не считается галлюцинацией,
но отсутствующие ожидаемые сведения остаются отсутствующими.

## Честное сравнение

Одинаковые вопросы, модель, провайдер, temperature и max_tokens. Каждый
вызов независимый; различается только наличие найденного контекста.
Один прогон не измеряет стабильность между повторными запусками.
Выходные токены, время и известная цена сохраняются как измерения;
неизвестная стоимость не заменяется нулём. Ошибки API не считать ответами.

Проверка готовности к сдаче: 20 сохранённых ответов, таблица десяти пар,
результаты поиска, описанные ограничения, воспроизводимые команды и видео.
