# Видео дня 10

[day10-panel-fast.mp4](day10-panel-fast.mp4) — 57,8 секунды, 1440×1100,
ускорение ×1,25, **без аудиодорожки**. Включено в Git.
Исходник `day10-panel-silent.mp4` (72,2 с) и промежуточные кадры игнорируются.

## Что на экране

1. **Код** — три настоящих фрагмента, вырезанных из файлов по границам функций,
   а не перепечатанных в шаблон: `context_history` из `strategies.py`,
   фиксированный список ключей из `facts.py`, `fork` из `branches.py`.
2. **Панель с реальной историей** — 13 ходов из завершённого живого прогона
   Sticky Facts (`results/project-facts.json`), не выдуманных.
3. **Переключение стратегий**. История не меняется, меняется только то, что
   уедет в модель:

   | Стратегия | Оценка входа | Уйдёт сообщений |
   | --- | ---: | ---: |
   | Полная история | 9 673 | 26 / 26 |
   | Sliding Window | 2 138 | 6 / 26 |
   | Sticky Facts | 2 225 | 7 / 26 |

4. **Ветка** `demo/alt` от текущей точки, переход в неё и обратно.
5. **Живой ход** — контрольный вопрос про память. Оплачены ровно два вызова:
   ответ и служебное обновление фактов (`live-calls.json`).
6. **Обновление страницы** — состояние поднялось с диска.

## Что видно честного, а не отрепетированного

Модель ответила правильно: «Актуальный срок: 25 октября», «Отменённый срок:
18 октября». Ровно на этом месте полная история в прогоне ошибалась и называла
отменённую дату.

При этом на строке «Что не входит в проект» стоит «нет данных — не упоминалось»,
хотя сценарий исключал онлайн-оплату. Это не сбой записи, а цена фиксированного
списка ключей: под исключённую функцию ключа нет, и в память она не попала.
Плата названа в [README дня 10](../README.md) и оставлена в кадре как есть.

Под ответом видно сообщение «новых сведений не оказалось; память прежняя» —
это нормальный отказ обновления, а не ошибка: контрольный вопрос новых фактов
не содержит.

## Артефакты

- `recording-source.json` — какой прогон дал первые 13 ходов.
- `recording-meta.json` — время ожидания живого хода, метрики трёх стратегий,
  память после хода, ошибки JavaScript (их нет).
- `live-calls.json` — два настоящих запроса и ответа.

## Повторная запись

Будут новые расходы из общего ledger (`results/budget.db`).

```bash
# Репетиция без сети и без денег — проверить хореографию кликов:
uv run day10/demo/serve_recording.py --env-file /путь/к/.env --offline
# Настоящая запись:
uv run day10/demo/serve_recording.py --env-file /путь/к/.env
# В другом терминале, Python с Playwright Chromium:
/opt/anaconda3/bin/python day10/demo/record.py
```

Нужны Playwright Chromium и ffmpeg. Зависимости агента — через `uv run`.
Скрипт пишет файлы с фиксированными именами: прежние артефакты сохранять
отдельно до запуска. Сервер записи останавливать через Ctrl+C, а не `kill`:
по SIGTERM не выполнится запись итогового отчёта о бюджете.

Ускоренная версия получена фильтром `setpts=PTS/1.25` из той же записи; сцены
не вырезались, ожидание ответа не сокращалось.
