# Day27 — результат 08.10.2026

Локальный веб-чат принимает свободный ввод, показывает потоковый ответ `qwen3:8b`,
продолжает разговор с последними восемью завершёнными ходами и очищает контекст
кнопкой «Новый чат». Backend: Python standard library → локальная Ollama.
RAG не подключён; сданные Day01–26 не изменены.

Код и видео готовы в ветке `day27-local-app`. Видео загружено в Google Drive,
коммит и push явно разрешены пользователем 08.10.2026 и выполняются.
Merge в main и пользовательская сдача не выполнены.

## Реальная интеграция

Проверено на Apple M2, 16 ГБ RAM, macOS 15.6.1 arm64, Python 3.14.0,
Ollama 0.33.3. Модель `qwen3:8b`, Q4_K_M; файл весов 5.23 ГБ.
Это размер на диске, а не пиковое потребление RAM.
Параметры: `think=false`, `num_ctx=4096`, `num_predict=384`.
Приложение слушало `127.0.0.1:8067`; Ollama — `127.0.0.1:11434`.

Метрики именно записанного дубля; время — `total_duration` Ollama,
включая её обработку запроса, не длительность ролика:

| Запрос | Результат | Время, с | Вход / ответ, токены | Финал |
| --- | --- | ---: | ---: | --- |
| Три шага создания чата | Три коротких пункта на русском | 13.06 | 62 / 65 | `stop` |
| Название проекта из предыдущего сообщения | `Маяк` | 1.87 | 153 / 4 | `stop` |
| После «Новый чат»: 17 + 25 | `42` | 0.53 | 35 / 3 | `stop` |

Payloads содержали соответственно 1, 3 и 1 сообщение. Во второй запрос вошёл
настоящий первый ответ; после сброса старых сообщений не было.
Все три ответа завершились настоящим конечным событием; ошибок страницы не было.

Первый ответ соблюдает формат, язык и длину, но описывает общий чат:
база данных, сервер, клиент. Он не упоминает подключение локальной LLM.
Это ограничение качества модели, сохранённое в полном ответе и видео;
сценарий не доказывает качество архитектурных рекомендаций.
Ответы просмотрены ответственным агентом; человеческая приёмка не заявляется.

## Границы проверки

Отключение интернета физически не проверялось. Приложение использует только
фиксированный loopback API и локальные статические файлы; cloud fallback отсутствует.
Долгие разговоры, пиковая RAM, одновременные пользователи и качество вне этих примеров
не измерялись. Ошибки провайдера проверены на заглушках, без остановки общей Ollama.
История живёт в странице: обновление страницы очищает её; максимум восемь завершённых
ходов и 12000 символов в передаваемом запросе. Для более длинного контекста нужен новый чат.
