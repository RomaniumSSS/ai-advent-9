# Практическая демонстрация Day23

Практическое видео снято и проверено; ссылка и детали приведены ниже. Панель показывает новый
вопрос «Что нужно сдать в Day21?», свежий поиск через SSH на замороженном
индексе, кандидаты/отбор A/E и две новые генерации DeepSeek / DeepInfra/fp8.
E читается из приватного selected-config.json; поиск не меняется для видео.

```sh
python3 day23/video/serve_live.py --operate --env-file /secure/.env
/tmp/day21-video-venv/bin/python day23/video/record_live.py --operate
```

Перед запуском оператор проверяет существование selected-config.json и
остаток **единого** day23/private/run-v1/ledger.json. Панель слушает только
127.0.0.1:8053, POST требует соответствующий Origin/Host. Без --operate сервер
даёт просмотр, но блокирует SSH/API. Съёмка также требует --operate, поскольку
нажатия выполняют внешние и платные операции. Автоматически эти команды
при подготовке кода не запускать.

Ключ читается только сервером из OPENROUTER_API_KEY или --env-file; браузеру
не выдаются ключ, путь .env, локальные пути, авторы и приватные чанки.
VIDEO01/A и VIDEO01/E используют общий бюджет Day23 $1, реальные цены,
резервы попыток и восстановление evaluate.py. Оплаченные ответы не
перезаписываются и не вызываются снова; повторная демонстрация явно помечает
их сохранёнными. Для требования «новые ответы» нужна первая успешная съёмка.

Отображаются тексты только assignment; обсуждения и личная заметка скрыты.
Если режим включил приватный источник в контекст, весь ответ этого режима
скрывается в видео; полный ответ остаётся в private. Это ограничение
публичной демонстрации, которое надо честно указать при сдаче. Список
кандидатов показывает cosine, mixed score и причины выбора/отсечения.

Playwright наследует PLAYWRIGHT_BROWSERS_PATH и использует
PLAYWRIGHT_CHROMIUM_EXECUTABLE, если задан. ffmpeg создаёт
Day23-practical.mp4 без звуковой дорожки. Скриншоты и WebM в frames содержат
только публичное отображение. Отсутствие приватного текста проверено
офлайн синтетическим кейсом; реальная браузерная съёмка выполнена и описана в разделе «Готовая запись».

## Приватная запись перед публикацией

Для содержательного сравнения полный текст новых ответов можно показать
только в явно включённом локальном private preview. Исходные тексты
обсуждений/заметки и авторы остаются скрыты в обоих режимах.

```sh
python3 day23/video/serve_live.py --operate --private-preview --env-file /secure/.env
/tmp/day21-video-venv/bin/python day23/video/record_live.py --operate --private-preview
```

Запись сначала сохраняется в day23/private/video-review/ (0700/0600).
Дополнительный --output-dir в этом режиме разрешён только внутри
 day23/private/. Recorder проверяет совпадение режима с сервером перед
нажатием кнопок. Без --private-preview действует прежнее скрытие ответов,
которые получили приватный контекст. Флаг не меняет поиск, контексты,
API-параметры или бюджет; дополнительных генераций для монтажа нет.

Родитель читает оба ответа и проверяет запись до переноса в публичный
video/Day23-practical.mp4. Цитаты/частные факты в ответах требуют маскирования
или редактирования записи. Приватные frames/WebM/MP4 не публиковать.
