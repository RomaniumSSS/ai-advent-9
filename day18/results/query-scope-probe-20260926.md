# Day 18 — диагностика поискового запроса, 26.09.2026

Проверка по просьбе пользователя перед изменением фильтра или формата. Код
Day 18, закреплённый RSS profile, SQLite с плановыми выпусками и Telegram не
изменялись. Среда: локальная macOS/Python 3.12; окно планового слота
26.09.2026: `[2026-09-25T16:00:00Z, 2026-09-26T16:00:00Z)`.

Сняты четыре выдачи официального [RSS поиска Хабра](https://habr.com/ru/rss/search/?q=%D0%98%D0%98-%D0%B0%D0%B3%D0%B5%D0%BD%D1%82%D1%8B&order_by=date&target_type=posts&hl=ru&fl=ru&limit=100)
с одинаковыми `order_by=date`, `target_type=posts`, `hl=ru`, `fl=ru`,
`limit=100`. Каждая прочитана действующим `parse_feed`; «в окне» означает
валидную статью, прошедшую текущий широкий topical gate.

Текущий поиск уже содержит описанный [DBA Agent](https://habr.com/ru/articles/1086740/),
но при нынешнем порядке по дате и бюджете шесть model-seen записей эта
статья остаётся вне анализа. Среди первых шести есть [Pony ORM: личный
пет-проект с ИИ-агентами](https://habr.com/ru/articles/1086790/): RSS excerpt
говорит о недельном спринте, применении агентов для программирования и
полученных изменениях проекта.

Один **диагностический**, не агентный вызов DeepSeek V4.1 Flash/DeepInfra
получил первые шесть очищенных RSS записей текущего запроса и временный prompt
«бизнес- или личное применение», не меняя рабочий prompt/validator. Модель
вернула `no_confirmed_cases`, два `possible_case` (Pony ORM и
[QA-инструмент](https://habr.com/ru/articles/1086968/)), четыре нерелевантные
категории. Это показывает, что расширение тематического критерия способно
дать непустую сводку из уже выбранных статей; фактическая доставка и проход
действующего бизнес-only validator этим тестом **не доказаны**. Ответ `stop`,
2208 prompt tokens, 621 completion tokens, `usage.cost=$0.00056994`.

Вывод ограничен одной датой и меняющейся RSS выдачей. Простое расширение
текстового поиска на `агент` добавило кандидатов, но опустило известный кейс
ниже. Узкое место для этого слота — отбор первых шести по дате и прежний
бизнес-only критерий; изменения источника и лимитов требуют отдельного решения.
